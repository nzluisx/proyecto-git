  # Sistema de Gestión de Reservas Hoteleras

## Nombre del proyecto
Sistema de Gestión de Reservas Hoteleras

## Descripción

Sistema web que permite gestionar las reservas de habitaciones de un hotel. Los usuarios pueden consultar las habitaciones disponibles, registrar una reserva y visualizar sus datos. El administrador puede gestionar habitaciones, clientes y reservas.

## Funciones principales

- Registrar clientes.
- Registrar habitaciones.
- Consultar habitaciones disponibles.
- Crear reservas.
- Modificar reservas.
- Cancelar reservas.
- Consultar las reservas realizadas.
- Gestionar el estado de las habitaciones.
